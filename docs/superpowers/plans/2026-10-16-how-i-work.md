**Goal:** 홈에 T자형 + 묻고 답하기 7줄의 HOW I WORK 섹션을 넣고, 각 줄을 상세 페이지의 해당 문단(`<WorkNote>`)으로 잇는다.

**Architecture:** 데이터는 `profile.ts`의 `howIWork` 한 곳. 홈 섹션(`HowIWork.tsx`)과 MDX 컴포넌트(`WorkNote.tsx`)가 같은 행을 읽는다. 새 상세 페이지 2개(festa, big-brother)는 Second Brain Template처럼 `projectPages()`에만 추가한다.

**Tech Stack:** Next.js 16 App Router, @next/mdx, Tailwind v4, node --test.

**Spec:** `docs/superpowers/specs/2026-10-16-how-i-work-design.md`

## Global Constraints

- main에서 작업, **push 금지**, 커밋은 사용자 요청 시에만.
- 사실은 볼트·저장소 원본에서 확인한 것만 (출처는 각 mdx 끝 `{/* 출처 */}` 주석). 팀원은 역할로만.
- 문체: 짧은 문장, 굵은 첫 줄, 다짐형 문장·이모지 카드 금지.
- WorkNote id는 `work-` 접두사 (PDF에서 모든 페이지가 한 문서라 id가 섹션 id와 겹치면 안 됨).

## Review Focus

1. 홈 링크 → 상세 문단: 고정 Nav(h-16)에 가리지 않아야 함 (`scroll-mt-20`).
2. 다크 모드에서 `:target` 강조 배경 위 글자 대비.
3. 375px에서 T자 가로 항목 줄바꿈 시 세로 막대가 가운데에 붙어 있어야 함.
4. PDF: `/projects/<slug>#work-…` 링크가 문서 안 그 문단으로 이동 (기존엔 프로젝트 시작으로만).
5. 오타 id: mdx에 없는 id를 홈이 가리키면 테스트가, 행이 없는 WorkNote는 빌드가 실패해야 함.
