## 무엇을 만들었나

**파티 패스포트**는 2026 I/O Extended: Hack the Beat 해커톤에서 약 3시간 동안 만든 웹 서비스입니다. 주제는 "파티를 더 잘 즐길 수 있는 서비스"였습니다. 파티에 가서도 아는 사람하고만 이야기하다 돌아오는 문제를 풀기 위해, 참가자가 서로의 QR을 태그해 "만난 사람 수"를 쌓고 증표를 모으게 했습니다. 파티가 끝나면 다시 만나고 싶은 사람을 비밀리에 고르고, 서로를 고른 쌍에게만 결과를 공개합니다.

이 해커톤은 AI 심사관 3명(창업가·엔지니어·투자자)이 채점하고, Playwright가 배포 링크에 직접 접속해 동작을 평가하는 방식이었습니다. 팀 4인큐(서새찬·홍의민·백지훈·이예람)로 참가했습니다.

## 맡은 역할

- 서비스 아이디어 제안 — 파티 패스포트 주제 제안 문서 작성과 v2~v4 개정
- 심사관이 AI라는 점에 착안해 창업가·엔지니어·투자자 심사관 페르소나를 구축하고 기획에 반영
- 호스트가 켜는 연락처 교환 유료 옵션 기획
- 프론트엔드·백엔드 PRD 작성

## 핵심 기능

- 앱 설치·로그인 없이 초대 링크와 이름 입력만으로 참여
- QR 태그와 4자리 코드 직접 입력으로 만난 사람 기록
- 첫 만남·아이스브레이커·파티 피플·파티 마스터·미션 완료·재회, 증표 6종 수집
- 친한 사람끼리만 뭉치지 않도록 1:1 미션 상대 배정
- 파티 후 비밀 상호 선택, 서로 고른 쌍만 공개
- 결과 화면에서 "다음 파티 만들기"로 참여자를 다음 호스트로 연결

## 기술적 결정

- **주제 확정 전에 배포 체계부터 구축** — 심사 에이전트가 코드가 아닌 배포 링크로 평가하기 때문입니다. 프론트는 GitHub Pages로 직배포하고, 프론트가 HTTPS이므로 API 도메인과 인증서도 먼저 준비했습니다.
- **"코드로 태그" 4자리 입력 폴백을 기본 기능으로 제공** — 자동화 브라우저는 카메라로 QR을 찍을 수 없기 때문입니다.
- **정원 초과 결제 단계를 화면에 구현하고 서버에서 402로 강제** — 브라우저에서 확인되지 않는 기능은 채점 상한에 걸리고, API를 직접 호출하는 우회도 막아야 했기 때문입니다.
