## 배경

**교회 아이들의 출석과 벌점·상점처럼, 함께 정한 "우리들의 규칙"을 보기 편하게 정리하려고 만든 앱입니다.** RuleBook은 출석, 경고, 벌점, 벌금을 기록하고 관리하는 모바일 앱입니다. 학생을 프로젝트(그룹) 단위로 묶어 관리하고, 그룹마다 경고를 몇 번 받으면 벌점이 되는지와 벌점당 벌금을 따로 정할 수 있습니다. 데이터는 기기에 저장되며 Excel 파일로 내보낼 수 있습니다.

요구사항 문서(PRD) 작성부터 화면 구현, 광고 연동, 스토어 배포까지 혼자 진행한 1인 개발 프로젝트입니다.

## 맡은 역할

- **PRD 작성** — MVP 범위(학생 관리, 경고·벌점·벌금, 다크/라이트 모드, 로컬 저장)와 MVP 이후 기능을 정리
- **핵심 로직** — 학생·그룹 CRUD, 경고의 벌점 자동 전환, 벌금 계산, 정렬·검색
- **출석 체크** — table_calendar 기반 날짜별 그룹 출석과 전체 출석 현황 화면
- **내보내기와 다국어** — 학생 데이터 Excel 내보내기·공유, 한국어/영어 전환
- **배포와 유지보수** — AdMob 배너 광고, 반응형 UI, Google Play·App Store 버전 업데이트

## 과정

**첫날 MVP를 만들었습니다.** 2025년 2월 23일 첫 커밋 당일에 "mvp단계 구현 완료"까지 진행했고, 이후 사흘 동안 순서 변경, 그룹 카드 편집, 1·2차 UI 작업을 이어갔습니다.

**MVP 이후로 미뤄둔 기능을 출시 전에 당겨왔습니다.** PRD에서는 출석 체크와 Excel 내보내기를 MVP 이후 기능으로 분류했지만, 3월 5일에 Excel 내보내기를, 3월 10~16일에 출석 체크를 먼저 만들었습니다. 그룹 출석은 커밋 메시지가 "success 90%", "Success 98%"를 거쳐 "Success to Attendance to group"이 될 때까지 여러 번 고쳐 완성했습니다.

**출시 후에도 필드를 늘렸습니다.** 3월 20일 정식출시 이틀 뒤 상점, 메모, 출석 일수 필드와 내보내기 개선을 담아 1.1.1을 배포했고, 3월 말 광고, 5월 반응형 UI 개선을 이어갔습니다. 2026년 7월에는 Android 16 타깃 SDK 요구에 맞춰 1.1.7로 버전을 올리고 iOS 최소 버전을 13.0으로 올렸습니다.

## 기술적 결정

### MVP는 로컬 저장, 서버는 이후로

- **상황**: PRD의 MVP 범위는 학생 관리와 경고·벌점·벌금 기록이었고, 저장 방식으로 shared_preferences를 명시했습니다.
- **결정**: 서버 없이 shared_preferences와 JSON 직렬화로 기기에 저장했습니다. 상태는 Provider 기반 서비스 계층(`StudentService`, `ProjectService`를 ChangeNotifier로 구성)으로 관리했습니다.
- **대안**: PRD는 Firebase 또는 Supabase를 이용한 클라우드 저장, 사용자 간 동기화, 멤버 초대를 MVP 이후 기능으로 분류했습니다.
- **결과**: 출시 이틀 뒤 상점·출석 일수 필드를 추가하면서 `fromJson`에 기본값 0을 두어, 해당 필드가 없는 기존 저장 데이터도 읽히게 했습니다.

### 경고 기준을 바꾸면 기존 기록도 새 기준으로 다시 계산

- **상황**: 경고가 그룹의 임계값에 도달하면 벌점 1점으로 바뀌고 경고는 0으로 돌아갑니다. 그런데 그룹 설정에서 임계값은 언제든 바꿀 수 있습니다.
- **문제**: 기준만 바꾸면 이미 새 기준을 넘긴 학생의 경고가 벌점으로 바뀌지 않은 채 남습니다.
- **결정**: 그룹 설정을 저장할 때 소속 학생 전원의 경고를 새 임계값으로 나눠, 몫은 벌점에 더하고 나머지만 경고로 남기도록 했습니다(`applyProjectSettingsToStudents`).

### 반응형 레이아웃은 flutter_screenutil로

- **상황**: 출시 두 달 뒤인 2025년 5월, 반응형 UI 작업을 진행했습니다.
- **결정**: flutter_screenutil을 도입해 iPhone 12 화면(390×844)을 기준 해상도로 두고, 화면과 위젯의 크기를 비율에 맞춰 조정했습니다.
