## 무엇을 만들었나

**경찰과 도둑**은 오프라인 술래잡기에 지도, 위치 공유, 실시간 게임 상태를 더한 Flutter 앱입니다. 경찰은 도둑을 찾아 QR로 체포하고, 도둑은 도망치거나 감옥에서 탈출하며 게임을 이어갑니다. iOS와 Android 양쪽 스토어에 출시했고, 한국어·영어·일본어를 지원합니다. 앱 외에 Spring Boot 게임 서버와 Next.js 공식 사이트가 함께 운영됩니다.

## 맡은 역할

- Flutter 앱 개발
- GitHub Actions와 Fastlane 기반 iOS TestFlight·Android Play Store 배포 자동화
- UX 개선
- iOS 잠금 화면 Live Activity와 Android 게임 진행 알림 등 잠금 화면 게임 현황 구현

## 핵심 기능

- GPS 기반 실시간 위치 추적과 구역 이탈 경고
- 호스트가 지도 위에 플레이 구역과 감옥을 직접 그려 설정
- 설정한 주기마다 도둑의 위치를 발자국으로 공개
- 경찰이 도둑의 QR을 스캔해 체포하고, 탈옥도 QR로 처리
- 같은 팀끼리만 대화하는 인게임 팀 채팅
- 방을 만들면 6자리 초대 코드와 QR이 자동 생성되며, 최대 150명까지 참여
- 게임 종료 후 결과와 이동 경로·거리를 담은 기록 공유

## 기술적 결정

- **REST는 조회·명령, STOMP는 실시간 이벤트로 분리** — 체포·탈옥 같은 요청은 REST로 보내고, 위치 공개·체포 이벤트는 STOMP로 받습니다. 연결이 끊겼다 복구되면 REST 상태 스냅샷으로 놓친 상태를 보정합니다.
- **Android 백그라운드 유지는 Foreground Service와 `PARTIAL_WAKE_LOCK`으로 해결** — 이전에는 배터리 최적화 해제를 요구하는 게이트로 게임 진입을 막았는데, 이것이 가장 큰 진입 장벽이 되었습니다. 내비게이션·음악 앱과 같은 방식으로 바꿔 사용자에게 설정 변경을 요구하지 않게 했습니다.
- **법적 문서의 정본은 웹, 앱은 웹뷰로 표시** — 앱 번들과 웹에 따로 있던 약관을 사람이 손으로 맞추면서 어긋날 위험이 있었고, 문구 하나를 고칠 때도 앱 재배포와 심사가 필요했기 때문입니다.
