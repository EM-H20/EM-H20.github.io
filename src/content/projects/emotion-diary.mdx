## 배경

React를 처음 공부하면서 강의의 섹션별 실습과 미션을 하나의 학습 저장소(onebite-react-study)에 커밋해 왔습니다. 감정 일기장은 그 마지막 섹션인 section12에서 만든 웹 앱입니다. 날짜별로 그날의 감정을 5단계 중 하나로 고르고 일기를 남기며, 홈에서는 한 달 단위로 모아 봅니다. React, React Router, Vite로 만들었고 혼자 진행한 학습 프로젝트입니다.

## 기술적 결정

### 목업 데이터 대신 localStorage에 저장

- **상황**: 일기 목록은 `App.jsx`에 적어 둔 목업 3건을 `useReducer`의 초기값으로 쓰고 있었습니다.
- **문제**: 메모리에만 있는 상태라 새로고침하면 작성한 일기가 사라지고 목업으로 돌아갔습니다.
- **결정**: 목업을 지우고, 생성·수정·삭제가 일어날 때마다 reducer 안에서 전체 목록을 localStorage에 저장하게 바꿨습니다. 앱이 뜰 때 저장된 값을 읽어 `INIT` 액션으로 복원하고, 읽는 동안에는 로딩 화면을 보여 줍니다. 새 일기의 id는 저장된 마지막 일기 다음 번호부터 이어집니다.
- **결과**: 새로고침 후에도 일기가 유지되었고, 같은 날 배포까지 마쳤습니다.
