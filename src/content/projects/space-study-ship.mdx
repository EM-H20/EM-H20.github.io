## 왜 만들었나

할 일 앱과 타이머는 기록을 남기지만, 쌓인 기록이 눈에 보이는 보상으로 이어지지는 않습니다. **우주공부선**은 **공부한 시간을 연료로 바꿔 행성과 지역을 해금하는** 학습 관리 앱입니다. 타이머 30분마다 연료 1을 줍니다.

2026년 1학기 창의학기제 1인 과제로, 앱 전체와 서버 도메인·인증 기능을 맡았습니다. 서버의 초기 구조와 배포 설정은 다른 기여자가 잡아 두었습니다.

## 기술적 결정

### 기록과 보상이 어긋나지 않게

- **문제**: 기록 저장과 연료 충전 중 하나만 성공하면 공부 기록과 보상이 어긋났습니다. 통신이 끊겨 같은 기록을 다시 보내면 연료가 두 번 들어갈 수도 있었습니다.
- **결정**: 저장·충전·학습시간 반영을 한 트랜잭션으로 묶고, 요청마다 `Idempotency-Key`를 붙였습니다.
- **결과**: 중간에 실패하면 셋 다 취소되고, 재전송해도 연료는 한 번만 들어옵니다.

### 로그인 세션: Redis 한 개 대신 기기별 DB 저장

- **상황**: 기존 서버는 Refresh Token을 Redis에 회원당 하나만 저장해, 한 기기만 로그인을 유지했습니다.
- **판단**: API 스펙은 기기별 관리를 가정했습니다. 토큰을 기기 테이블로 옮기고 토큰에 기기 ID를 넣었습니다.
- **결과**: 기기마다 따로 로그인됩니다. 기존 사용자의 한 번 강제 로그아웃은 설계 때 감수했습니다.

### 같은 오류 세 번: 국소 수정 대신 구조 정리

- **문제**: 로그아웃과 게스트 전환에서 인증 코드와 저장소가 서로를 참조해, Riverpod 순환 의존성 오류가 났습니다.
- **판단**: 처음 두 번은 문제가 난 곳만 고쳤습니다. 세 번째에 인증 코드가 데이터 계층을 바로 부르도록 전체를 정리했습니다.

## 결과

- 학기 말 앱·서버 연동 베타를 완성하고, Google Play 비공개 테스트로 게시했습니다.
- 행성 8개·지역 30개, 배지 25개, 서버 API 23개
- 소셜·배지의 서버 연동은 남은 과제입니다.
