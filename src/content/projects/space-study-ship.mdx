## 무엇을 만들었나

우주공부선(Space Study Ship)은 공부한 시간만큼 우주를 탐험하는 학습 관리 앱이다. 할 일을 등록하고 타이머로 공부 시간을 재면 30분마다 연료 1이 쌓이고, 이 연료로 행성과 지역을 해금한다. 누적 학습 시간이나 연속 학습일 같은 목표를 채우면 배지를 받는다. 2026년 1학기 창의학기제 과제(학생들의 학습 지속성 향상을 위한 게이미피케이션 기반 Todo + Timer 서비스 개발)로 진행했다.

## 맡은 역할

창의학기제에 개인으로 참여해 Flutter 앱과 Spring Boot·PostgreSQL 서버를 함께 개발했다. Git 기록상 프론트엔드 커밋 대부분과 백엔드의 할 일·카테고리, 타이머 세션, 탐험, 회원 탈퇴, 닉네임, 소셜 로그인 검증 기능을 본인이 작성했다. 백엔드 초기 멀티모듈 구조와 CI/CD 설정 일부는 다른 기여자의 커밋이다.

## 핵심 기능

- 할 일·카테고리 관리와 공부 타이머, 학습 시간에 따른 연료 적립
- 연료로 해금하는 탐험 콘텐츠(행성 8개, 세부 지역 30개)
- 6개 범주 25개 배지(획득 상태는 기기에 저장)
- 회원가입 없이 쓰는 게스트 모드와 Google·Apple 로그인 후 서버 저장 방식 동시 지원
- 서버 API 23개(인증 6, 할 일·카테고리 8, 타이머 3, 연료 2, 탐험 4)

## 기술적 결정

- 저장 요청마다 식별키 부여 — 통신이 끊겨 같은 기록이 다시 전송되면 연료가 두 번 지급될 수 있어, 이미 처리한 요청에는 기존 결과만 돌려주게 했다.
- 기록 저장·연료 충전·할 일 학습시간 반영을 하나의 트랜잭션으로 처리 — 중간에 실패하면 모두 취소되게 했고, 행성·지역 해금도 연료 차감과 함께 처리했다.
- 인증 관리 코드가 데이터 접근 계층을 직접 호출하도록 구조 변경 — 로그아웃, 게스트 전환, 회원 탈퇴 과정에서 인증 관리 코드와 저장소가 서로를 참조해 생긴 오류를 해결했다.

## 결과

학기 말 기준 앱과 서버가 연동된 베타 버전을 완성했고, 최종 발표 당시 Google Play에 비공개 테스트 버전을 올렸다. 학기 중 보고서 기준 프론트엔드·백엔드 자동 테스트 240개 이상이 통과했다. 소셜 화면은 샘플 데이터로 구성돼 있으며, 소셜과 배지의 서버 연동은 남은 과제다.
