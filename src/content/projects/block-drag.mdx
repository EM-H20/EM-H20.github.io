## 무엇을 만들었나

Block Drag는 매 턴 주어지는 블록 3개를 드래그 앤 드롭으로 그리드에 배치해 가로·세로 라인을 완성하는 모바일 퍼즐 게임이다. 그리드는 6x6과 8x8 중에서 고를 수 있고, 보드에는 장애물이 무작위로 배치된다. 남은 블록을 하나도 놓을 수 없으면 게임이 끝나며, 보상형 광고를 보고 이어서 플레이할 수 있다.

## 맡은 역할

Git 기록상 모든 커밋이 본인 계정으로 작성된 1인 개발 프로젝트다. 게임 로직, UI, 사운드, 광고 연동, 스토어 배포용 빌드까지 직접 진행했다.

## 핵심 기능

- 블록 배치 점수, 라인 클리어 점수, 콤보 보너스, 전체 클리어 보너스로 구성된 점수 체계
- 3회 연속 라인 클리어로 활성화되고 최대 10단계까지 오르는 콤보 시스템, MAX 콤보 도달 시 길이 10~15칸의 Fantastic 블록 제공
- 점수 구간에 따른 티어 시스템과 게임 통계, 크리티컬 라인 미션
- ShowcaseView 기반 인터랙티브 튜토리얼
- 배경음악·효과음과 진동 피드백, 라이트/다크 테마
- 게임 상태 자동 저장과 이어하기, 앱이 백그라운드로 가면 자동 일시정지
- AdMob 배너·전면·보상형 광고

## 기술적 결정

- Clean Architecture 기반 4계층(core·domain·data·presentation)으로 전체 리빌드 — 보드, 점수, 콤보, 티어, 미션 규칙을 domain 서비스로 두고 화면 코드와 분리했다.
- Riverpod 코드 생성과 Freezed 불변 엔티티 — 게임 상태를 copyWith로만 갱신해 상태 변경 흐름을 한 방향으로 유지했다.
- SharedPreferences 로컬 저장 — 게임 상태와 최고 점수를 서버 없이 기기에 저장한다.
- Supabase 기반 Google OAuth 로그인을 통합했다가 비활성화 — 로그인 기능을 개발 중으로 전환하고 Supabase 의존성을 제거한 상태로 배포를 이어갔다.
- upgrader와 GitHub에 둔 appcast 파일로 업데이트 안내 — 새 버전이 나오면 앱 안에서 업데이트를 알린다.
