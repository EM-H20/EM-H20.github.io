## 배경

로스트아크 레이드 일정을 정하고 보스 공략을 찾아보는 일을 디스코드 안에서 할 수 있게 만든 봇 "플래닝"입니다. 날짜 투표, 보스 관문별 공략 이미지, Gemini AI 질의응답, 매주 공지사항 링크 전송 기능을 Python과 discord.py로 혼자 만들었고, Oracle Cloud 서버에서 구동했습니다.

## 맡은 역할

- **1인 개발** — 기능 구현, 공략 데이터 관리, Oracle Cloud 서버 구동

## 과정

**큰 파일 하나로 시작했습니다.** 첫 커밋에 1,400줄이 넘는 `main.py` 하나로 재부팅·상태 변경, 단일·중복 일정 투표와 현황 표시, 보스 공략, Gemini 챗봇이 들어 있었습니다. 같은 날 공략 코드의 변수 이름을 phase에서 gate(관문)로 통일했습니다.

**쓰면서 기능을 붙였습니다.** 12월에는 매주 수요일 오전 10시 5분 공지사항 링크 자동 전송, 봇 이름 "플래닝"과 README, 보스 난이도 이모지 선택, 이용약관·개인정보처리방침 링크를 차례로 더했고, 쓰지 않게 된 로스트아크 API 설정은 지웠습니다.

**게임 업데이트를 따라갔습니다.** 2025년 1월 신규 보스 모르둠을 추가하면서, 같은 날 보스 공략 코드 구조를 정리했습니다.

## 기술적 결정

### 보스별 함수 대신 데이터 파일 하나로

- **상황**: 보스 13종마다 명령 함수가 따로 있었고, 함수마다 임베드를 만들고 관문별 이미지를 보내는 비슷한 코드가 반복됐습니다. 모르둠을 추가할 때도 같은 모양의 함수를 하나 더 써야 했습니다.
- **결정**: 보스 이름, 설명, 난이도, 관문 수, 이미지 경로를 `boss_data.json`으로 옮기고, 보스별 명령은 공통 처리 함수를 부르기만 하도록 바꿨습니다.
- **결과**: `main.py`가 1,478줄에서 1,091줄로 줄었습니다.

### 난이도는 다시 입력하는 대신 이모지 반응으로

- **상황**: 난이도 없이 `/보스 발탄`만 입력하면 "`/보스 발탄 노말`처럼 다시 입력하라"는 안내만 보여 줬습니다.
- **결정**: 안내 메시지에 🇳·🇭 반응을 달고, 명령어를 입력한 사람이 10초 안에 누르면 그 난이도의 공략을 바로 보여 주게 바꿨습니다. 난이도를 함께 입력하는 방식도 그대로 쓸 수 있습니다.
