## 왜 만들었나

"어떤 과목을 들어야 하지?", "방학에는 뭘 해야 하지?" 저희 팀도, 주변 친구들도 하던 고민입니다. 학생들은 수강편람을 일일이 찾거나 선배에게 물어서 정했습니다.

**완익세종**은 성적표 Excel 파일과 희망 진로를 넣으면, Google Gemini가 **학기별 추천 과목과 방학별 활동을 담은 로드맵**을 만들어 주는 서비스입니다.

제13회 세종대학교 SW-AI 해커톤에서 3인 팀으로 하룻밤 동안 만들었습니다.

## 맡은 역할

프론트엔드를 혼자 맡았습니다. 백엔드는 별도 저장소의 Spring Boot 서버였습니다.

- **화면·API Routes** — 성적표 업로드와 파싱, 역량 분석, Gemini 로드맵 생성
- **챗봇 '세박사'** — 과목·교수 검색
- **백엔드 연동** — 응답 변환 어댑터

## 기술적 결정

### 백엔드 없이 먼저: Mock·Local·Backend 모드

- **상황**: 백엔드가 다른 저장소에서 동시에 만들어지고 있었습니다.
- **판단**: UI용 Mock, Gemini를 바로 부르는 Local, Spring Boot를 쓰는 Backend 모드를 두고 환경 변수로 바꿨습니다.
- **결과**: 시작 후 2시간이 안 돼 업로드부터 로드맵까지 첫 흐름을 띄웠습니다.

### 새벽 3시의 400 에러: 폴백을 고치는 대신 없애기

- **상황**: 백엔드는 상태 코드 말고는 아무 정보도 주지 않았습니다. 추적해 보니 로컬로 넘어가는 폴백이 여전히 백엔드 주소로 요청을 보내고 있었습니다.
- **선택지**: 폴백 주소를 로컬로 고치는 방법, 폴백 경로에도 어댑터를 붙이는 방법, Backend 모드에서 폴백을 없애는 방법이 있었습니다.
- **판단**: 폴백을 살리면 백엔드 연결 문제가 계속 가려질 수 있었습니다. 그래서 Backend 모드에서는 폴백을 없애고 오류를 그대로 돌려주게 했습니다.

### 명세와 다른 응답: 어댑터에서 받아내기

- **상황**: 고치고 나니 로드맵이 비어 있었습니다. 응답 필드명이 명세와 달라, 어댑터가 모든 과목을 걸러 냈습니다.
- **판단**: 백엔드 수정을 기다리지 않고, 두 형식을 모두 받되 경고 로그를 남겼습니다.
- **결과**: 로드맵이 표시됐고, 임시 조치라고 문서에 남겼습니다.
