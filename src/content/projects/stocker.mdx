## 무엇을 만들었나

**Stocker**는 주식 투자를 처음 시작하는 사람을 위한 금융 교육 앱입니다. 챕터별 이론 학습, 퀴즈, 오답노트, 출석 체크, 투자 성향 분석을 한 앱에서 제공합니다. Flutter로 iOS와 Android를 함께 개발했고, 백엔드는 Node.js REST API(JWT 인증)입니다. 팀 **돔황촤 코스피**로 진행했습니다.

## 맡은 역할

Flutter 프론트엔드 개발을 맡았습니다. 저장소 최초 구성과 상태관리·라우팅 구조를 잡았고, 이후 상태관리를 Provider에서 Riverpod으로 옮겼습니다. 인증 가드 라우팅과 서버 에러 메시지 통합, API 통신 로깅, 퀴즈 중간 이탈 방지, 로그인 후 투자 성향 분석 유도, 스플래시 화면, Android 릴리스 빌드의 네트워크 오류 수정을 진행했습니다.

## 핵심 기능

- 챕터별 주식 이론 학습과 진도 관리
- 챕터별 O/X 퀴즈와 정답 해설
- 틀린 문제를 자동으로 모으는 오답노트
- 캘린더 기반 출석 체크와 출석 퀴즈
- 20개 문항으로 5가지 투자자 유형을 분류하는 투자 성향 분석과 포트폴리오 차트
- flutter_quill 기반 학습 노트

## 기술적 결정

- **기능별 `data / domain / presentation` 3계층 구조와 Repository 패턴** — 데이터 소스를 추상화하고 테스트를 쉽게 하기 위해서입니다.
- **Mock·Real Repository를 `useMock` 상수 하나로 전환** — 백엔드 완성 전에도 UI 개발을 진행하기 위해서입니다. Mock으로 UI를 만든 뒤 실제 API로 연결하는 순서로 개발했습니다.
- **Provider에서 Riverpod으로 전환** — 타입 안전성과 테스트 용이성을 위해서입니다. 기능별 Provider를 단계적으로 Notifier로 바꾼 뒤 Provider 패키지를 제거했습니다.
